# Compact Card Size Reductions

## Changes to Make Cards Smaller:

### 1. **Padding Reductions:**
- CardContent: `p-4` → `p-3` (16px → 12px)
- Top banner: `px-4 py-2` → `px-3 py-1.5` (less height)
- Status badges: `px-3 py-2` → `px-2 py-1` 
- Action buttons: `px-4 py-3` → `px-3 py-2`

### 2. **Font Size Reductions:**
- Table number: `text-4xl sm:text-5xl` → `text-2xl` (60px → 24px)
- Order amount: `text-2xl sm:text-3xl` → `text-xl` (36px → 20px)
- Status badges: `text-sm` → `text-xs` (14px → 12px)
- Timer: `text-lg` → `text-sm` (18px → 14px)
- Banner text: `text-sm` → `text-xs` (14px → 12px)
- Order number: `text-sm` → `text-xs`

### 3. **Spacing Reductions:**
- Gap between elements: `gap-3` → `gap-2` (12px → 8px)
- Margin bottom: `mb-3` → `mb-2` (12px → 8px)
- Button height: `h-12` → `h-9` (48px → 36px)

### 4. **Icon Size Reductions:**
- Large icons: `size-5` → `size-4` (20px → 16px)
- Small icons: `size-4` → `size-3` (16px → 12px)
- Banner icons: `size-4` → `size-3`

### 5. **Button Reductions:**
- Font size: `text-base` → `text-sm` (16px → 14px)
- Height: `h-12` → `h-9` (48px → 36px)
- Icon size: `size-5` → `size-4`

Apply these to the WaiterOrderCard component for a more compact design.
